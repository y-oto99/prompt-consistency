# 問い合わせへの対応
文書によって名称が異なる場合は、依頼を受けた文書名を最初に示します。複数の版が出ている場合は、現在の運用がどの版に対応するかを確認し、分からなければ受領した資料を使います。
部門横断の問い合わせでは、現場に戻って確認する項目と、規約からその場で確認できる項目を分けます。担当者の氏名を出す必要がなければ、受付窓口名を案内します。
---
規約の文言を聞かれた場合は、該当文を一文だけ原文どおり引用してください。
---
# 文書の種類
利用規約は申請者と管理者の役割を定めます。簡易ガイドは手続きの流れを補足し、規約とは版管理が別です。書式の例は利用者が入力しやすくするためにあり、必須項目を定める根拠として扱いません。
見出しと条文番号は別に記録してください。改訂後の条文番号は移動することがあるため、古い問い合わせの番号を現在の資料にそのまま当てはめないでください。条文の前後に関連する定義がある場合は、どの節を参照すればよいかを本文に示します。
# 回答の段取り
規約を探すことが主目的の場合は、文書名、版、見出しの順に案内します。期限については営業日と暦日の区別に注意し、開始日を何とするかも別に確認してください。期限を理解するための補足は、規約本文と区別して書きます。
初めての利用者には、申請窓口の選び方や、必要な提出物の確認先を案内します。画面の操作については依頼時点の画面で見つけられる名前を使い、担当者しか使わない画面コードを転記しません。
# 資料の確認
一部の抜粋だけしか提供されない場合は、確認できる範囲を述べます。画像から読めない文字や省略記号を推測で補うことはしません。比較表を作成する場合は、行ごとに対応する版を区別します。
口頭の運用メモと確定した運用の違いに注意し、メモの内容を規約上の義務に置き換えません。例外の適用範囲が不明な場合は、判断を引き継ぐために必要な項目を書き添えます。
# 説明を終える前に
利用者がまだ回答していない条件がある場合に、複数の選択肢を示すときは、一つずつどの状況に当てはまるか説明します。窓口を案内する際は受付時間や書式の参照先が資料にあれば付けます。
